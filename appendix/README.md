# appendix/

The live runs behind the video clips and the pipeline figure, on the V5 leg mesh (2026-10-21), with their frames and
run notes. Each subfolder's README says which run it is, what its readings were, and what the pictures do and do not
show. `clips/` at the repository root holds the same mp4s under one folder for convenience.

- `video_2026-10-21_v5/`: the plain live run (the speed quoted in the paper, 56.4 ms median per frame) and its frames at every press depth.
- `video_2026-10-21_v5_cutview/`: the cut-away illustration runs (`element_colours/`, `smooth/`); slower, speed not quoted. `smooth/raw_frames/` (untracked cache) holds the raw frame arrays `fig_pipeline_frame.py` recomposes.
